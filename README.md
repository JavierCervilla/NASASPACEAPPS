# Ventana Lunar

> Landing at the lunar south pole is parking where the Sun lasts days and Earth disappears for weeks.
> Ventana Lunar tells you when and where you can.

**NASA Space Apps Challenge 2026** · challenge *CLPS Lunar Mission Browser* · Madrid, 14-15 November 2026.

Pick a south pole landing site and a date range. Ventana Lunar shows, hour by hour, whether a lander there has
**Sun** (power), **sees Earth** (comms), or **both**: a landing window. It also shows which Deep Space Network antenna
is listening (Goldstone, Canberra or Robledo de Chavela, Madrid).

**Status:** preparation. The product is built during the hackathon weekend, as the challenge rules require; until then
this repo holds the tooling, CI and deploy pipeline, and a placeholder page.

## How it works

```text
JPL Horizons API ──► pipeline/ (Python, run once, cached) ──► public/data/*.json ──► static web (Astro + React)
                                                                                      ├─ calendar strip (MVP)
                                                                                      ├─ 2D polar map (MVP)
                                                                                      ├─ 3D globe (Three.js)
                                                                                      └─ DSN mini globe
```

- **No backend.** All ephemerides are precomputed from JPL Horizons and shipped as static JSON, so nothing can fail
  during the demo and deploying is a `git push`.
- **One clock.** A single store holds the selected site and the model time (UTC hour); every view reads it and none
  computes its own, so the globe and the strip can never disagree.

## Repository layout

| Path | What |
|---|---|
| `src/pages/` | Astro pages (one screen) |
| `src/components/` | React islands (strip, map, globe, card, DSN) |
| `src/lib/` | Pure TypeScript: store, window logic, formatting (unit-tested) |

| `pipeline/` | Python precompute from JPL Horizons |
| `tests/unit/`, `tests/e2e/` | Vitest and Playwright |
| `docs/diagrams/` | Architecture diagram |

## Develop

Requires Node 22 (`.nvmrc`) and, for the pipeline, Python 3.

```sh
npm install
npm run dev          # http://localhost:4321/NASASPACEAPPS/
npm run lint && npm run typecheck && npm test && npm run build && npm run e2e
```

## Data sources

- [JPL Horizons API](https://ssd-api.jpl.nasa.gov/doc/horizons.html) (NASA/JPL): Sun and Earth azimuth/elevation from
  each lunar surface site; Moon elevation from each DSN complex.
- NASA CLPS and Artemis landing sites from the challenge resources.
